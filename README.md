# CampusConnect — University Portal

CampusConnect is a Java web portal for organizing student and faculty operations in one place. It explores CRUD workflows, search, filtering, and role-aware administration in a university context.

## Highlights

- Student and faculty record management
- Search and filtering for common administrative tasks
- Role-aware admin workflows
- MySQL persistence with a server-rendered HTML/CSS interface

## Technology

Java Servlets · MySQL · HTML · CSS · JDBC

## Engineering focus

The project demonstrates end-to-end portal fundamentals: translating operational needs into CRUD screens, keeping administrative actions explicit, and shaping a domain model around real users rather than disconnected demo entities.

## Roadmap

- Migrate the service boundary to Spring Boot REST endpoints
- Add automated tests and validation coverage
- Add Docker Compose and GitHub Actions CI
- Introduce a React/TypeScript client and accessibility pass

This is a portfolio learning project. Demo data should remain non-sensitive.
